# 🧶 Yarn Loop

실을 감아 니트 그림을 풀어내는 컬러 매칭 퍼즐. 모바일 게임 *Yarn Loop: Knit Puzzle*에서 영감을 받은 개인 토이 프로젝트입니다.

**▶ 바로 플레이: https://excel8057.github.io/yarn-loop/** (설치 없이 휴대폰·PC 브라우저에서)

`main`에 푸시하면 GitHub Actions가 GitHub Pages로 자동 배포합니다 (`.github/workflows/pages.yml`).

## 플레이 방법

- 아래 대기열에서 **맨 앞 보빈**을 탭하면 그림 둘레의 컨베이어 벨트에 올라갑니다.
- 보빈은 벨트를 한 바퀴 돌면서, 각 줄에서 **가장 바깥에 보이는 스티치가 같은 색이면** 감아옵니다.
- 보빈의 숫자만큼 다 감으면 사라집니다.
- 다 못 채운 채 한 바퀴를 돌면 **보관함**으로 갑니다. 보관함의 보빈은 탭해서 다시 보낼 수 있습니다.
- 보관함이 가득 찬 상태에서 보빈이 또 돌아오면 실패. (레벨마다 1번, 보관함 +1로 이어하기 가능)
- 벨트에는 동시에 최대 5개까지 올라갑니다.

총 400 스테이지. 1~11은 직접 만든 레벨이고, 12~400은 시드 기반 생성기가 만듭니다(같은 번호는 항상 같은 그림). 31번째 이후 10단계마다 ★ 어려운 스테이지가 나옵니다. 로컬 서버(`localhost`)에서는 `?level=N`을 붙여 원하는 레벨을 바로 열 수 있습니다(테스트용, 공개 주소에서는 무시됨).

## 실행

빌드 도구나 의존성이 없습니다. ES 모듈이라 `file://`로는 열리지 않으니 정적 서버로 띄우세요.

```bash
node serve.mjs    # http://localhost:5173
```

GitHub Pages에 그대로 올려도 동작합니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/game.js` | 게임 상태와 규칙 (벨트, 체크포인트 스캔, 보관함, 승패) |
| `src/art.js` | 팔레트, 픽셀 아트 도구(paint·upscale·outline), 손그림 모음 |
| `src/levels.js` | 직접 만든 레벨 11개, 전체 스테이지 수 |
| `src/generator.js` | 스테이지 생성기: 모양 틀×무늬, 손그림 색 바꾸기, 만다라, 꽃, 픽셀 친구 + 난이도 곡선 |
| `src/render.js` | Canvas 렌더링 (스티치, 보빈, 벨트, 실 애니메이션) |
| `src/main.js` | 루프, 입력, HUD/오버레이, 진행도 저장 |
| `src/audio.js` | WebAudio 합성 효과음 |

레벨 추가는 `src/levels.js`의 `LEVELS`에 픽셀 아트 문자열을 넣거나 `paint()`로 도형을 그리면 됩니다. 문자 하나가 `PALETTE`의 색 하나, `.`은 빈 칸입니다. `upscale()`로 작은 손그림을 키우고 `outline()`으로 검은 테두리를 두를 수 있습니다.
